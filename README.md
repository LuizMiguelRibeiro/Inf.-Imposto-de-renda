# Inf.-Imposto-de-renda
Desenvolvi uma planilha no Excel para organizar dados de Imposto de Renda. O projeto centraliza informações de titular, informes bancários e notas mensais, contando com validações automáticas, menus padronizados de bancos e fórmulas de soma e agregação de dados (Com a ajuda do professor Felipe Aguiar da DIO).
